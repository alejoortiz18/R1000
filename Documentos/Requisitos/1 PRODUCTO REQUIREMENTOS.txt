VISIÓN DEL PRODUCTO Rickoin es una plataforma web que permite a los usuarios participar en rifas digitales mediante el uso de una moneda virtual interna, garantizando: transparencia en los procesos trazabilidad financiera cumplimiento regulatorio en Colombia seguridad en transacciones El sistema está diseñado para operar como una solución escalable tipo fintech + gaming regulado , con posibilidad de certificación ante entidades como Coljuegos. 2. OBJETIVO DEL PRODUCTO Desarrollar una plataforma digital que: centralice la venta de boletas de rifas gestione una moneda virtual interna ( Rickoin ) automatice sorteos y distribución de premios garantice cumplimiento normativo permita auditoría completa del sistema 3. ALCANCE DEL PRODUCTO Incluye Registro de usuarios con validación de identidad Compra de moneda virtual ( Rickoin ) Participación en rifas Gestión de boletas Sistema de premios Sistema de retiros Panel administrativo Notificaciones por correo Seguridad con 2FA Auditoría de transacciones No incluye (en esta fase) aplicación móvil nativa integración con APIs externas transferencias entre usuarios 4. DESCRIPCIÓN GENERAL DEL SISTEMA El sistema se compone de dos módulos principales: 4.1 Plataforma de Rifas Permite: visualizar artículos consultar estado de rifas comprar boletas revisar historial 4.2 Plataforma Financiera Permite: comprar Rickoin gestionar saldo solicitar retiros validar identidad (2FA) 5. ACTORES DEL SISTEMA Usuario se registra compra Rickoin compra boletas participa en rifas recibe premios solicita retiros Administrador crea rifas define parámetros gestiona estados controla operación Sistema calcula punto de equilibrio para rifas ejecuta sorteos valida reglas envía notificaciones 6. MODELO DE NEGOCIO Fuente de ingresos margen entre valor de boletas y costo del artículo comisión por uso de plataforma penalización del 10 % ( parametrizable por el administrador de la aplicación) en premios en dinero Moneda Rickoin : 1 Rickoin = 1000 COP ( parametrizable por el administrador de la aplicación) uso exclusivo dentro del sistema ( moneda del sistema) sin retiro 7. REGLAS DE NEGOCIO Rifas Cada rifa debe tener: máximo de boletas precio por boleta fecha de inicio y fin de rifa punto de equilibrio Punto de equilibrio mínimo de boletas necesarias si no se cumple → devolución si se cumple → sorteo válido Premios El ganador puede: recibir el artículo recibir dinero en Rickoin (-10 %) ( parametrizable por el administrador de la aplicación) Retiros tiempo de procesamiento: 6 a 10 días cancelación disponible durante 5 días requiere validación 2FA 8. SEGURIDAD autenticación por email y contraseña verificación por correo expiración de código (15 min) (parametrizable por el administrador de la aplicación) validación de identidad (documento identidad ) 9. NOTIFICACIONES El sistema enviará correos para: registro validación compras premios retiros 10. CUMPLIMIENTO LEGAL El sistema debe alinearse con: regulación de juegos de azar en Colombia ( FUTURO) lineamientos de Coljuegos ( FUTURO) protección de datos personales normativas fiscales de DIAN (FUTURO) 11. TRANSPARENCIA El sistema debe mostrar al usuario: estado de rifas cantidad de boletas vendidas punto de equilibrio reglas claras 12. RIESGOS DEL PRODUCTO Técnicos concurrencia en compra de boletas inconsistencias de saldo errores en devoluciones Legales falta de autorización regulatoria incumplimiento de normas 13. ARQUITECTURA GENERAL plataforma web en .NET Core MVC en capas (NO hay API) base de datos SQL Server despliegue en Azure arquitectura limpia por capas 14. MÉTRICAS DE ÉXITO número de usuarios registrados volumen de ventas de boletas tasa de participación tasa de finalización de rifas tiempos de respuesta del sistema 15.
